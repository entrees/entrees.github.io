Exploring Layers and Ripples support page

About this page

This page provides support materials for the book Exploring Layers and Ripples: Studying English with Computer Parsing (978-1-84890-522-1) by Alastair Butler published by College Publications. This page links to versions of the parser described in the book that you can download. This page also lists examples to parse from the book. This is given as help to the reader who might copy and paste listed examples into one of the available versions of the parser to experience parsing the book discusses.

For additional assistance and for reporting mistakes found in the book, please contact the author at ajb129 __AT__ hirosaki-u __DOT__ ac __DOT__ jp

Available versions of the parser

There are three versions of the parser available:

  • There is an on-line version you can use through a web based portal when connected to the internet. This version has links to further examples with links to click to see parse results.
  • There is a precompiled windows executable made with the Mercury compiler. To use this version, you should download the executable onto a 64 bit version of windows and double click the executable whereupon you will be able to enter examples and see parse results.
  • There is the source Prolog version that is given in the book. You can obtain a download of this code. The download contains a README.txt file with details of how to load the program into the XSB Tabling Prolog system that you will need to have installed on your local computer.

Note: How content to parse is entered depends on which version of the parser is being used. Details of the appropriate format are given in the next section.

A listing of content from the book

The following lists chapter and section headings from the book together with the content of examples to be parsed. Information for undertaking a parse is given in two formats:

  • The first is the version that appears in the book and is the content that should be entered at a Prolog interpreter prompt that has the Prolog version of the parser code preloaded.
  • The second is a version not listed in the book that presents word analysis with an inline format used by both the on-line version of the parser and the windows executable version of the parser that is compiled by Mercury. With this inline format, words are given followed by an open square bracket character (‘[’) and then the tag label for the word (including extensions and codes) followed by a closing bracket character (‘]’), e.g.:
    A[D] man[N] smiled[VBD;_I_] .[PUNC]
